# Paseo Composer Assistant

> 状态：开发版，可安装到带本地草稿桥补丁的 Paseo 0.15.0。没有配置辅助模型时不会发出任何请求。

为 [Paseo](https://github.com/getpaseo/paseo) 的当前会话提供输入建议：用户先查看建议，再决定是否写回草稿；发送始终由用户自己决定。

安装、配置和停用见 [INSTALL.md](INSTALL.md)；发送范围和保存内容见 [PRIVACY.md](PRIVACY.md)。
网页宿主补丁的源码、构建和恢复方法见 [host-bridge](host-bridge/README.md)。

## 当前进度

已经能在原生输入框里完成"手动优化 → 预览 → 采纳或保留原文"的完整流程：

- 输入框上方出现「优化」胶囊；选中文字时只处理选区，没有选区时处理整段。
- 生成建议前检查：输入框可编辑、输入法空闲、文字非空；输入法组字中直接拒绝。
- 建议在紧凑浮窗里显示；只有点「采纳建议」才写回草稿，写回不发送消息。
- 写回带原版本；草稿或会话变化后旧建议自动失效；失败保留原文并说明原因。
- 代码块、行内代码、网址、路径和用户填写的受保护术语会检查是否被改动，缺一个就拒绝采纳。
- 设置页可填接口地址、模型、密钥文件、受保护术语、字符上限和超时。
- 可选的「输入续写」（默认关闭）：句子结束后请求一次续写，在输入框下方显示建议，用户可采纳或忽略；每台机器滚动一小时有上限，默认 10 次。
- 可选的「回复后下一句」（默认关闭）：助手回复结束后，把最后一条回复发给辅助模型，起草一句用户可以接着说的话；写入输入框，不发送。两项自动功能共用一小时上限。
- 优化浮窗内可分别开关两项自动功能，并可进入完整设置；开启前会提示发送范围、可能费用和每小时上限。

辅助模型只支持 OpenAI 兼容的文字接口；密钥从用户指定、权限 600 的普通文件读取，不写进设置、日志或仓库。发送内容只有本次要优化的那段文字，不含附件、其他会话或工具结果。

已验证：类型检查和局部测试通过；原开发版用真实模型（本机 Command Code 中转）检查过整段、选区、自动续写和回复后下一句的建议与写回。后续修复在隔离实例中检查过胶囊、未配置模型提示和快捷开关；修复后的版本尚未重新进行真实模型写回测试。

未验证／未做：

- 真实模型只测了本机 Command Code 中转的 DeepSeek V4.1 Flash；其他服务未验证。
- 手机端未验证；官方 Paseo 没有草稿桥，插件在这些宿主上不会出现胶囊。
- 自动续写只在句末触发；两项自动功能每台机器共享一小时上限。

## 计划功能


- 手动优化整段文字或选中部分，在紧凑浮窗中比较、采纳或保留原文。
- 可选的输入续写和回复后建议；默认关闭自动建议。
- 在输入区附近提供快捷设置，并说明辅助模型、内容发送范围和可能费用。
- 草稿或会话发生变化时丢弃旧建议；保护附件、引用、中文输入法和宿主命令。

## 已有项目与复用

- [DSH Composer Assistant](https://github.com/Mr-Elk/dsh-composer-assistant)：计划复用或提取其与宿主无关的文本保护、上下文和请求调度逻辑，保留原版权和许可证。DSH 专用界面、模型调用与存储不能直接当成 Paseo 接入。
- [PromptKit](https://github.com/hungcuong9125/paseo-prompt-kit)：已有 Paseo 草稿改写，可作为功能和兼容性对照；其直接替换草稿的交互与本项目计划的预览后采纳不同。

## 后续核对

- 在修复后的版本上重新检查真实模型建议、写回、撤销与取消。
- 在其他支持的客户端检查输入法、附件和宿主命令；没有验证的客户端保持未知。

Paseo 0.15.0 的公开插件接口目前未发现原生草稿和选区读写接口。基于网页内部结构的方案需要单独说明兼容范围；在宿主的 `/` 命令菜单按 Tab 可能执行归档命令的问题解决前，不默认用 Tab 采纳建议。
